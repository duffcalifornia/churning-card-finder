# churning-card-finder

The source behind [whichcreditcardshouldiget.com](https://whichcreditcardshouldiget.com), a free tool for
deciding which credit card to apply for: a rules engine (5/24, issuer velocity limits, lifetime and family rules,
the Marriott eligibility matrix, and more) plus the scripts that keep its card catalog and welcome offers current.

Point valuations are from Frequent Miler's [Reasonable Redemption Values](https://frequentmiler.com/reasonable-redemption-values-rrvs/).

This repository is public so anyone can see how the site works. It isn't licensed for reuse.
